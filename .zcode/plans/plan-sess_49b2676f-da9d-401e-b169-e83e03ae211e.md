# Settings Redesign — Hub, Sub-pages & Their Contents

## Scope (everything under `/settings`)
1. New `settings/layout.tsx` — desktop sub-navigation
2. `settings/page.tsx` — hub (mobile) + General overview (desktop)
3. 5 sub-pages: `profile`, `funds`, `notifications`, `android-app`, `danger`
4. 5 content components inside them: `ProfileImageManager`, `FundConfigForm`, `NotificationSettings`, `AppDownloadCard`, `DeleteAccountDialog`

## 1. `settings/layout.tsx` (new, client)
- Desktop only (`hidden lg:flex`): sticky left column (~220px) with "Settings" label + vertical nav (General, Profile, My Funds, Reminders, Android App, Danger Zone) using the same tinted icons as the mobile hub; active state via `usePathname()`.
- Mobile: renders `children` untouched — hub + back-headers already handle mobile nav.
- Section config (href, icon, tint, label) extracted to a shared module used by both the hub rows and this nav.

## 2. `settings/page.tsx`
- **Mobile**: keep current hub structure (hero + groups) — polish spacing only.
- **Desktop**: replace the long stacked page with a **General overview**: profile summary card (avatar, name, email, fund count) + a 2-col grid of section cards, each with icon, title, one-line description, and current state (e.g. "3 funds", "Push on / Email off") linking to its sub-page.

## 3. Sub-pages (all 5)
- Keep `MobileDetailHeader` on mobile; desktop `<h1>` + description stays (framed by sub-nav now).
- Unify container: same max-width, spacing, and `animate-fade-in` everywhere.

## 4. Component redesigns (the "inside the pages" part)

### `profile-image-manager.tsx`
- From one flat row to a proper profile card: larger avatar (h-20) centered on mobile / left on desktop, name + email, "Change photo / Remove" as real buttons (not underlined text), fund-count as a stat chip.

### `fund-config-form.tsx`
- Replace the bordered list rows with **fund cards**: name as title, fee/SIP/NAV/start-date as a small 4-stat grid (tabular-nums), edit + delete icon buttons top-right.
- Empty state: friendly "No funds yet — add your first fund" card with CTA.
- Search + pagination kept, restyled to match (rounded inputs, quieter pagination).
- Dialog: 2-column field grid on `sm+`, preset select pinned at top.

### `notification-settings.tsx`
- Channels become two clean rows in one card with Bell/Mail icons in tinted tiles (matching the hub tints), status pill (On/Off/Blocked), and the existing switches.
- Schedule note moves into a subtle footer strip inside the card.

### `app-download-card.tsx`
- Phone-icon hero row + description; Download button with `Download` icon; install steps as a numbered vertical list with connector dots instead of `<ol>`; "How to install" toggle restyled as a ghost button.

### `delete-account-dialog.tsx`
- Danger card: `AlertTriangle` tile, clearer consequence list ("3 funds, 27 entries will be deleted" — pass counts in), destructive button full-width on mobile.
- Dialog: keep type-DELETE confirmation; add a red-tipped header band.
